# Getting help

These projects have one maintainer, Juan, and are worked on in spare time. Help is best effort, and there is no guaranteed response time.

- **Bugs:** open an issue with the bug report form in the project's repository. Steps to reproduce and versions make it much faster to fix.
- **Questions:** open an issue in the project's repository and add the `question` label. Check the README and existing issues first.
- **Ideas and features:** open an issue with the feature request form before you write code, so we can agree on the approach.
- **Security problems:** never in a public issue. Follow [SECURITY.md](SECURITY.md).
- **Conduct:** see [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md); reports go to oss@hizkiajuan.com.
