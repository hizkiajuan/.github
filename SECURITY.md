# Security policy

This policy covers every public repository of [hizkiajuan](https://github.com/hizkiajuan) that has no `SECURITY.md` of its own.

## Supported versions

Only the latest release of each project receives security fixes.

## Reporting a vulnerability

Please do not open a public issue. Report the problem privately through GitHub: open the affected repository, then **Security → Report a vulnerability**. If you cannot use GitHub, email oss@hizkiajuan.com.

Include the project and its version, the steps to reproduce, and the effect you observed. You will get a first reply within 7 days. When the fix is released, the advisory is published and credits you unless you ask otherwise.
